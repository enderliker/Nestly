## Reporting

This is a private repository. Report vulnerabilities through a private GitHub
security advisory to the repository owner. Do not open a public issue.

Include the affected version, a minimal reproduction, and the impact you
believe it has. Do not include a live bot token in the report.

## Supported versions

Only the latest release receives security fixes.
